# 每周总结

本目录存放 Sentinel-X **周总结**，与主路线图 [`../ROADMAP.md`](../ROADMAP.md) 配合使用。

## 如何使用

1. 每周一或周末，复制 [`TEMPLATE.md`](TEMPLATE.md) 为 `YYYY-Www.md`（ISO 8601 周编号）。
2. 对照 ROADMAP §5 中对应 **Wn** 任务勾选完成情况。
3. 更新 ROADMAP §7「周总结索引」表格中的状态与链接。

## 文件命名

```text
docs/weekly/2026-W22.md   # 2026 年第 22 周
docs/weekly/2026-W23.md
```

## 当前索引

见 [`ROADMAP.md` §7](../ROADMAP.md#7-每周总结规范)。
