# Dev Log

Short, public-facing development logs — optimized for **resume / portfolio** readers.

| vs | `docs/weekly/` |
|----|----------------|
| **dev-log** | 5-minute daily/weekly snapshot: Completed / Focus / Blockers / Next |
| **weekly** | Detailed engineering weekly report (Chinese), metrics, task IDs |

## How to write

1. Copy [`TEMPLATE.md`](TEMPLATE.md) → `YYYY-MM-DD.md`
2. Keep bullets factual; link to weekly report for depth
3. One file per significant checkpoint (not every typo fix)
